# 매체별 엑셀 데이터 취합 · GA4 통합 분석 정의서

매체별(네이버·메타·카카오·구글·엑스·크리테오·틱톡·당근 등) RAW 데이터를 표준 스키마로 자동 취합하고, 선택한 GA4 속성 데이터와 결합해 통합 분석 보고서(PPT·엑셀)를 만드는 기능의 정의서입니다.

| 정의 | 파일 |
|---|---|
| 표준 스키마 · 헤더 동의어 · 매체 정의 · GA4 유료 매체 규칙 | `src/config/mediaConfig.js` |
| 파일 읽기 (xlsx · csv 인코딩 판별) | `src/services/media/fileReader.js` |
| 헤더/매체/VAT 인식 · 행 정규화 | `src/services/media/normalizer.js` |
| 세션별 작업 공간 · 사용자 보정 | `src/services/media/mediaStore.js` |
| 집계 · 파생 지표 | `src/services/media/mediaAggregator.js` |
| 표준/통합 엑셀 | `src/services/media/excelExporter.js` |
| GA4 유료 유입 조회 | `src/services/integration/ga4Traffic.js` |
| 매체 × GA4 매칭 · 인사이트 | `src/services/integration/integrator.js` |
| 통합 보고서 PPT | `src/services/integration/integratedPpt.js` |

---

## 1. 처리 흐름

```
RAW 업로드 (여러 파일 · 드래그 앤 드롭)
   ↓  파일 읽기: xlsx(exceljs) / csv·tsv (UTF-8 · UTF-8 BOM · UTF-16 · CP949 자동 판별)
시트 선택 · 헤더 행 탐지
   ↓  상단 25행 중 표준 컬럼과 가장 많이 일치하는 행 (지표 컬럼 1개 이상 필수)
컬럼 매핑 · 매체 판별 · VAT 판별
   ↓
행 정규화 (합계 행 제외 · 날짜/숫자 파싱 · 광고비 VAT 기준 통일)
   ↓
표준 스키마 통합 → 화면 요약 / 표준 엑셀
   ↓  (선택) GA4 유료 유입 조회 → 매체 · 일자 · 캠페인 매칭
통합 분석 → 미리보기 / 통합 PPT / 통합 엑셀
```

자동 인식 결과(매체 · 헤더 행 · 컬럼 매핑 · VAT)는 화면에서 파일별로 수정할 수 있고, 수정 즉시 표준 행이 다시 계산됩니다.

## 2. 표준 스키마

| 키 | 표준 컬럼 | 유형 | 주요 헤더 동의어 (우선순위 순) |
|---|---|---|---|

| `media` | 매체 | 코드 | (파일 단위로 지정) |

| `adGroup` | 광고그룹 | 문자 | 광고그룹, 광고 세트 이름, Ad set name, Ad group |
| `creative` | 소재/키워드 | 문자 | 키워드, 소재, 광고 이름, Ad name, Keyword |
| `device` | 기기 | 문자 | PC/모바일 매체, 디바이스, 기기, Device |

| `reach` | 도달 | 숫자 | 도달, Reach |
| `videoViews` | 동영상 조회 | 숫자 | 동영상 재생, ThruPlays, Video plays |

헤더 비교 규칙

- 소문자화 · 공백/`_`/`-`/`·` 제거 후 비교합니다.
- 괄호 안 단위는 무시합니다. `총비용(VAT포함,원)` → `총비용`, `Amount spent (KRW)` → `amountspent`
- **완전 일치만** 인정합니다. `클릭률(%)`, `평균클릭비용`, `결과당 비용`, `CPC(링크 클릭당 비용)` 같은 비율·단가 컬럼이 지표로 잘못 매핑되지 않도록 하기 위함입니다.
- 한 헤더는 한 필드에만, 한 필드는 한 헤더에만 배정됩니다. 동의어 앞쪽이 우선입니다.
  (메타 파일에 `클릭(전체)`와 `링크 클릭`이 함께 있으면 `링크 클릭` 사용)

## 3. 매체 · VAT 판별

### 3.1 매체

| 매체 | 파일명 키워드 (+10점) | 헤더 시그니처 (+1점/개) | GA4 소스 매칭 |
|---|---|---|---|
| 네이버 | naver, 네이버, nsa, 검색광고, gfa, 파워링크 | PC/모바일 매체, 평균클릭비용, 총비용 | `/naver/` |
| 메타 | meta, facebook, 페이스북, 메타, instagram | 지출 금액, 광고 세트 이름, 링크 클릭, 보고 시작 | `/facebook\|instagram\|meta\|^fb$\|^ig$\|threads/` |
| 카카오 | kakao, 카카오, moment, 모먼트, 비즈보드 | 소재, 전환수(7일) | `/kakao\|daum/` |
| 구글 | google, 구글, adwords, youtube | Impr., Conv. value, Currency code | `/google\|youtube/` |
| 엑스(트위터) | twitter, 트위터, 엑스, x_ads, xads | Billed engagements, Url clicks, Engagement rate, Time period | `/^(x\|x.com\|t.co)$\|twitter/` |
| 크리테오 | criteo, 크리테오 | Displays, Post-click sales, Post-view sales | `/criteo/` |
| 틱톡 | tiktok, 틱톡 | Clicks (destination), CTR (destination), 클릭수(목적지) | `/tiktok/` |
| 당근 | 당근, daangn, karrot | — (파일명으로 판별) | `/daangn\|karrot\|당근/` |
| 기타 | — | — | (매칭하지 않음) |

- 신뢰도: 10점 이상 `자동 인식` · 2점 이상 `추정` · 그 외 `확인 필요`(기타로 분류, 경고 표시)
- 새 매체는 `MEDIA` 배열에 항목을 추가하면 됩니다. `label`은 보고서·표에 쓰는 짧은 이름, `fullLabel`은 업로드 화면 선택 목록에 쓰는 이름입니다. (예: 엑스 / 엑스(트위터))
- 당근은 표준 헤더(일자·캠페인·소재·비용 등)가 카카오와 비슷해 **파일명에 '당근'이 없으면 카카오로 추정될 수 있습니다.** 화면에서 매체를 바꿔 주세요.

### 3.2 VAT

- 광고비 헤더에 `VAT포함`이 있으면 원본 VAT 포함, `VAT별도/제외`가 있으면 별도로 인식합니다.
- 표기가 없으면 **VAT 별도로 가정**하고 경고를 표시합니다. (파일별 체크박스로 변경 가능)
- 표준 광고비 기준은 작업 공간 단위로 선택합니다. (기본: VAT 별도)

| 원본 | 표준 기준 | 변환 |
|---|---|---|
| VAT 포함 | VAT 별도 | ÷ 1.1 |
| VAT 별도 | VAT 포함 | × 1.1 |

## 4. 행 정규화

| 항목 | 규칙 |
|---|---|
| 빈 행 | 모든 셀이 비어 있으면 건너뜀 (제외 건수에 미포함) |
| 합계/요약 행 | 첫 셀 · 캠페인 · 광고그룹 · 소재 · 일자 중 하나가 `합계/총계/소계/전체/Total/Summary`로 시작하면 제외 |
| 요약 행 추정 | 캠페인 컬럼이 있는데 캠페인·광고그룹·소재가 모두 비어 있으면 제외 (메타 내보내기 첫 행 등) |
| 일자 | `YYYY-MM-DD`, `YYYY.MM.DD.`, `YYYY/MM/DD`, `YYYYMMDD`, `YYYY년 M월 D일`, `M/D/YYYY`, `Sep 1, 2026`, 엑셀 날짜 셀·일련번호 지원. 인식 불가 행은 제외 |
| 기간 표기 | 시작일과 종료일이 같으면(`2026/09/01 - 2026/09/01`, X 내보내기 형식) 해당 일자로 처리. `2026.09.01 ~ 2026.09.21` 처럼 기간이면 일자 없는 **기간 합계 행**으로 보관 (일별 추이 제외, 합계·캠페인 분석에는 포함) |
| 숫자 | `₩`, `원`, `KRW`, `,`, `%`, 공백 제거. `-`·빈 값은 0, `(123)`은 음수. 해석 불가 값은 0 처리 후 건수 경고 |
| 캠페인 없음 | 캠페인 컬럼이 없거나 값이 비면 `(캠페인 미지정)` |

파일별 결과에는 형식 · 인코딩 · 시트 · 헤더 행 · 표준 행 수 · 제외 행(사유별) · 기간 · 광고비 · 경고가 표시되고, 엑셀 `업로드_로그` 시트에 그대로 남습니다.

## 5. 집계 · 파생 지표

| 지표 | 계산 |
|---|---|
| CTR | 클릭 ÷ 노출 × 100 |
| CPC | 광고비 ÷ 클릭 |
| CPM | 광고비 ÷ 노출 × 1,000 |
| CVR | 전환 ÷ 클릭 × 100 |
| CPA | 광고비 ÷ 전환 |
| ROAS | 전환매출 ÷ 광고비 × 100 |

분모가 0이면 `-`로 표기합니다. 매체 보고 전환(`conversions`)은 매체별 기여 기준이 달라 **매체 간 단순 비교용이 아닙니다.** GA4 통합 시에는 GA4 키 이벤트 기준 지표를 함께 제공합니다.

## 6. GA4 통합

### 6.1 GA4 조회

```jsonc
{
  "dateRanges": [{ "startDate": "<분석 시작일>", "endDate": "<분석 종료일>" }],
  "dimensions": [{ "name": "date" }, { "name": "sessionSource" }, { "name": "sessionMedium" }, { "name": "sessionCampaignName" }],
  "metrics": [{ "name": "sessions" }, { "name": "engagedSessions" }, { "name": "keyEvents" }, { "name": "totalRevenue" }],
  "dimensionFilter": {
    "filter": { "fieldName": "sessionMedium",
                "stringFilter": { "matchType": "FULL_REGEXP", "value": "<GA4_PAID_MEDIUM>", "caseSensitive": false } }
  },
  "limit": 100000
}
```

- `GA4_PAID_MEDIUM` 기본값: `cpc, ppc, cpm, cpv, cpa, cpt, display, banner, sa, da, gfa, video, ad(s), paid*, *_paid, social_ad`
  → 사내 utm_medium 운영 규칙에 맞게 `mediaConfig.js`에서 조정합니다.
- 속성에 따라 `keyEvents`/`totalRevenue`가 조회되지 않으면 `conversions` → 매출 제외 → 세션만 순으로 자동 재시도합니다.
- 사이트 전체 세션(필터 없음)을 별도로 조회해 **유료 유입 비중**을 계산합니다.
- 분석 기간 기본값은 업로드한 매체 데이터의 최소~최대 일자이며, 화면에서 변경할 수 있습니다. 기간 밖 매체 행은 제외됩니다.

### 6.2 매칭 규칙

| 단계 | 규칙 |
|---|---|
| 매체 | GA4 `sessionSource`가 매체의 `ga4Source` 정규식과 일치 → 해당 매체 유입 |
| 일자 | 동일 일자 |
| 캠페인 | 같은 매체 안에서 캠페인명을 소문자화하고 공백·`_`·`-`·`.`을 제거해 **완전 일치** |

매칭되지 않은 GA4 유료 유입은 사유와 함께 따로 보여 줍니다.

| 사유 | 의미 |
|---|---|
| 매체 규칙 미일치 | 어느 매체 정규식에도 해당하지 않는 소스 (예: mobon) |
| 미업로드 매체 | 매체는 식별되지만 해당 매체 RAW 를 올리지 않음 |
| 캠페인명 불일치 | 매체는 맞지만 utm_campaign 이 매체 캠페인명과 다름 |

### 6.3 통합 지표

| 지표 | 계산 | 비고 |
|---|---|---|
| 클릭→세션 도달률 | GA4 세션 ÷ 매체 클릭 × 100 | 재방문·다중 세션으로 100% 초과 가능 |
| 세션당 비용 | 광고비 ÷ GA4 세션 | |
| 참여율 | 참여 세션 ÷ 세션 × 100 | |
| GA4 CPA | 광고비 ÷ GA4 키 이벤트 | |
| GA4 ROAS | GA4 매출 ÷ 광고비 × 100 | 매출 지표 조회 가능 시 |
| 상관계수 | 일별 클릭 vs GA4 세션 피어슨 r | 5일 이상일 때 |

## 7. 통합 보고서

### 7.1 PPT

기존 GA4 보고서와 같은 디자인 시스템(`theme.js`)을 사용합니다.

| 슬라이드 | 내용 |
|---|---|
| 표지 | `MEDIA` · 분석 기간 · 분석 매체 · GA4 속성 · 대표 지표 3종 |
| M1 매체 성과 요약 | KPI(광고비·노출·클릭·CPC) · 매체별 표 · 광고비 비중 도넛 · 인사이트 |
| M2 일별 추이 | KPI(일평균 광고비·최대 집행일·일평균 클릭·일평균 GA4 세션) · 매체별 누적 막대 · 클릭 vs GA4 세션 선 · 인사이트 |
| M3 매체 × GA4 | KPI(유료 세션·도달률·세션당 비용·ROAS/CPA) · 매체별 통합 표 · 클릭 vs 세션 막대 · 인사이트 *(GA4 연동 시)* |
| M4 캠페인 성과 | KPI(캠페인 수·매칭 수·미매칭 광고비·최대 캠페인 비중) · 상위 10 캠페인 · 인사이트 · GA4 미매칭 유입 |
| (선택) GA4 기본 분석 | 핵심 요약 · 분석 개요 · 7개 영역 (같은 분석 기간) |

GA4 미연동이면 M3을 생략하고 M4는 매체 보고 기준(CTR·CPA)으로 구성합니다.

### 7.2 엑셀

엑셀은 두 가지로 내려받습니다.

| 버튼 | 대상 기간 | 시트 | 사용 조건 |
|---|---|---|---|
| 표준 데이터 엑셀 (전체 기간) | 업로드한 전체 기간 | 공통 5개 | 항상 |
| GA4 통합 분석 엑셀 (선택 기간) | 2단계 분석 기간 | 공통 5개 + GA4 3개 | GA4 연동(속성 연동 또는 샘플 GA4) 시에만 활성화 |

GA4 없이 만들면 두 파일의 내용이 같아지므로, GA4 통합 분석 엑셀은 GA4 연동 시에만 제공합니다.


| 시트 | 내용 |
|---|---|
| 요약 | 매체별 광고비·비중·효율 지표 + 합계 |
| 매체xGA4 | 매체별 통합 지표 *(통합 엑셀 · GA4 연동 시)* |
| 캠페인_GA4매칭 | 캠페인별 매칭 여부와 GA4 지표 *(동일)* |
| GA4_미매칭유입 | 미매칭 GA4 유료 유입과 사유 *(동일)* |
| 표준_통합데이터 | 전체 표준 행 (필터 · 틀 고정) |
| 일별_추이 | 일자 × 매체 광고비 + 합계 지표 |
| 캠페인별 | 매체 · 캠페인별 지표 |
| 업로드_로그 | 파일별 인식 결과 · 매핑 · 제외 행 · 경고 |

| `.xls`(구버전) | 업로드 목록에 오류로 표시하고 `.xlsx`로 저장 후 업로드 안내 |
| 지원하지 않는 형식 · 20MB 초과 · 20개 초과 | 오류 메시지 |
| 헤더 행 인식 실패 | 파일 오류 표시 (지표 컬럼 포함 여부 안내) |
| 매체 인식 실패 | `기타`로 분류하고 선택 요청 경고 |
| 필수 지표 컬럼 없음 | 광고비/클릭/노출 누락 경고 (해당 지표 0) |
| 일자 컬럼 없음 | 기간 합계 데이터로 처리, 일별 추이에서 제외 |
| 선택 기간에 데이터 없음 | 통합 분석 요청 시 오류 |
| GA4 미로그인 | 401 → 화면에서 로그인 안내 |
| GA4 지표 비호환 | 지표 세트를 줄여 재시도 |
| 작업 공간 한도 | 30만 행 초과 시 업로드 거부 · 8시간 미사용 시 자동 정리 |

## 10. 운영 전 확인 필요 사항

- **실제 매체 RAW 형식** — 현재 동의어·시그니처는 각 매체의 대표적인 다운로드 형식 기준입니다. 운영 중인 실제 파일(특히 네이버 GFA, 카카오 비즈보드, 메타 영문 UI 내보내기)로 한 번 검증하고, 인식되지 않는 헤더는 `mediaConfig.js` 동의어에 추가하세요.
- **VAT 기준** — 헤더에 표기가 없는 매체는 VAT 별도로 가정합니다. 매체별 실제 청구 기준과 다르면 매체 기본값을 설정값으로 추가하는 것을 권장합니다.
- **utm_medium 규칙** — GA4 유료 유입 판정 정규식이 사내 UTM 규칙과 맞는지 확인이 필요합니다.
- **캠페인명 매칭** — 매체 캠페인명과 utm_campaign 이 다르게 운영되면 매칭되지 않습니다. 별도 매핑 테이블(매체 캠페인 ↔ utm_campaign) 업로드 기능은 후속 과제입니다.
- **작업 공간 저장소** — 업로드 데이터는 서버 메모리에 세션 단위로 보관됩니다. 다중 인스턴스 배포나 장기 보관이 필요하면 외부 저장소로 교체해야 합니다.
